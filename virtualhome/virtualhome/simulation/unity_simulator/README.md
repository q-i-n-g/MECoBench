# Unity Simulator Communication

This package contains the modified `UnityCommunication` Python API used by
MECoBench to communicate with the released Unity executable.

The evaluation code uses:

- `reset`
- `expand_scene`
- `add_character`
- `add_character_camera`
- `camera_count`
- `camera_image`
- `instance_colors`
- `environment_graph`
- `render_script`
